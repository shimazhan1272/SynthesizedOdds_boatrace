# ボートレースAI予想＆合成オッズ Webアプリ

過去約26万レースのビッグデータから最尤推定した統計ロジットモデル（Plackett-Luce型条件付きロジット）を用いたボートレースAI予想と、公式サイトの3連単オッズリアルタイム照会、合成オッズ計算、最適資金配分機能を1画面に統合したWebアプリケーションです。

---

## 1. アプリ概要と主な特徴

- **統計モデルAI予想**: 2022年1月〜2026年10月の264,035レースを対象に最尤推定した係数を使用。出走表データ（勝率、級別、平均ST、モーター2連率等）に加え、直前展示情報（展示タイム、スタート展示スリット隊形、風速・風向・波高）を総合的にスコア化。
- **公式3連単オッズ連携＆合成オッズ**: 公式サイト（boatrace.jp）の3連単120通りのオッズを自動取得。複数買い目を選んだ際の「合成オッズ」や、どの買い目が的中しても同等以上の払戻が得られる「100円単位最適購入配分」を瞬時に算出。
- **当日データ（today.json）最優先**: 当日レース開催時は、約3分間隔で更新される最新の `today.json` を最優先で参照。
- **当日開催場の絞り込み表示**: 当日日付選択時は、実際にレースを開催している場のみをプルダウンに表示。本日全レースが終了した場も状態を明示。
- **締切10分前赤文字＆終了レース二重線（取り消し線）**: レース番号プルダウン（例: `6R 16:10締切`）および結果ヘッダーにおいて、現在時刻に応じて自動判定。締切10分前は赤色、締切・終了済みは二重線（取り消し線）で表示。
- **スリット隊形SVG可視化**: スタート展示の進入コース・並び順・STをコース別のグラフィックで図示。
- **前付け・進入コース補正**: スタート展示で枠なりと進入が崩れた場合（前付け等）を検知し、ペナルティとコース別係数を自動適用。
- **PWA対応**: スマートフォンやPCのホーム画面にインストールして全画面アプリとして動作。
- **ローカルストレージ保存**: 最後に使った年月日・場・レース番号、買い目点数、モデルスライダー値、購入予算を自動保存し次回起動時に復元。
- **外部有料サービス・AIキー不要**: 完全無料で動作。

## 2. セットアップと起動

### 開発環境での実行
```bash
# 依存パッケージのインストール
npm install

# 開発サーバ起動（ポート3000）
npm run dev
```
ブラウザで `http://localhost:3000` を開きます。

### プロダクションビルド
```bash
npm run build
```
`dist/` フォルダに静的アセット一式が出力されます。

### GitHub Pages等での公開手順
1. 本リポジトリをGitHubにプッシュします。
2. GitHubリポジトリの `Settings` > `Pages` に移動します。
3. `Build and deployment` の Source を `GitHub Actions` に設定し、Vite静的サイトデプロイのワークフローを有効化（または `npm run build` の出力を `gh-pages` ブランチにプッシュ）します。
4. 静的ホスティング上でも、CORSプロキシおよびHTML貼り付けフォールバックにより全機能が動作します。

## 3. データ取得の仕組みとプロキシ設定

### 出走表と直前情報（Boatrace Open API）
1. **当日データ最優先**: `https://boatraceopenapi.github.io/api/v1/today.json`
   - 約3分間隔の定期更新データを取得し、鮮度を最優先。
2. **出走表フォールバック**: `https://boatraceopenapi.github.io/programs/v2/{YYYY}/{YYYYMMDD}.json`
3. **展示情報フォールバック**: `https://boatraceopenapi.github.io/previews/v2/{YYYY}/{YYYYMMDD}.json`
4. **公式サイト直接解析フォールバック**: Open APIで未反映の場合は、公式サイト（`boatrace.jp/owpc/pc/race/beforeinfo`）をプロキシ経由でスクレイピング。

### 公式サイト3連単オッズ取得とプロキシ
`boatrace.jp` はブラウザからのクロスオリジンアクセス（CORS）を制限しているため、以下の順序でフォールバック取得します：
1. **Vite開発サーバ プロキシ**: `vite.config.ts` に設定された `/proxy/boatrace` を経由。
2. **パブリックCORSプロキシ**: `allorigins.win` / `corsproxy.io` を経由。
3. **HTML手動貼付**: 「HTML手動貼付」ボタンから公式サイトのオッズ画面ソースを貼り付けて解析可能。

#### 自前プロキシサーバ（Cloudflare Workers）の作成例
自身のCloudflare Workers（無料枠）を立てる場合は、以下のスクリプトをデプロイするだけで高速・安定したプロキシとして利用できます：

```javascript
export default {
  async fetch(request) {
    const url = new URL(request.url);
    const targetUrl = url.searchParams.get("url");
    if (!targetUrl) return new Response("Missing target url", { status: 400 });

    const response = await fetch(targetUrl, {
      headers: {
        "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36",
        "Referer": "https://www.boatrace.jp/"
      }
    });

    const body = await response.text();
    return new Response(body, {
      headers: {
        "Access-Control-Allow-Origin": "*",
        "Content-Type": "text/html; charset=UTF-8"
      }
    });
  }
};
```

## 4. 予想モデル係数調整の使い方（折りたたみパネル）

統計モデルの主要項を、利用者の見立てに合わせて微調整できます。動かすと即座に全買い目が再計算されます。

- **スライダー範囲**: -3.0 〜 +3.0（刻み0.1、初期値0.0）
- **実効係数の計算式**:
  $$\text{実効係数} = \text{基準値} \times \left(1 + \frac{\text{スライダー値}}{3}\right)$$
- **スライダー値の意味**:
  - `0.0`: 標準（基準値そのまま、1倍）
  - `+3.0`: 影響度を2倍に強化
  - `-3.0`: その項の影響を完全無効化（0倍）
- **対象項目**:
  1. **当地2連率**: 乗り慣れた水面での巧拙を重視したい場合はプラスへ
  2. **モーター2連率**: 機力・エンジンの相場を重視したい場合はプラスへ
  3. **展示タイム補正**: 直前の伸び足・行き足を重視したい場合はプラスへ
- **「0に戻す」ボタン**: クリックでいつでも標準の推定値に戻せます。

## 5. 展示タイム・気象データ・進入コースの手動修正

直前情報がまだ発表されていない時間帯や、独自に「風が強まってきた」「前付けで進入が変わる」と判断した場合に手動で値を修正できます。

- **各艇の展示タイム**: 6艇分の数値を手動入力
- **風速 (m/s)**: 0〜20m/s
- **風向**: 追い風（コード5）、向かい風（コード13）、右横風（コード9）、左横風（コード1）など
- **波高 (cm)**: 0〜50cm
- **進入コース (1〜6)**: 各艇の進入コースを変更可能（枠番と異なる内寄り進入になった艇には前付けペナルティが自動計算されます）
- 入力値の変更は即時再計算に反映されます。

## 6. 推奨買い目とフォーメーション表示

- **買い目点数**: 3連単、2連単、3連複をそれぞれ0〜30点のプルダウンで設定可能。0点に指定した券種は非表示になります。
- **フォーメーション集約**:
  - `1-2-345`、`1-245-2`、`12-12-3456` のように、選択された買い目集合と100%一致する組み合わせのみをカンマなしのコンパクトなフォーメーション行として集約表示。
  - 余分な買い目の混入は一切発生せず、フォーメーション行の点数は内包される実買い目数と正確に一致します。
  - 各フォーメーションを展開して個別の確率・オッズ・期待値目安（EV）を確認可能。
- **確率の意味**: モデルが推定したその着順でゴールする確率（%）。フォーメーション行は含まれる買い目の合算確率です。
- **期待値の目安（EV）**: 「モデル推定確率 × 取得オッズ」。1.0以上は緑色でハイライト表示されます（※利益を保証するものではありません）。

## 7. 3連単オッズ・合成オッズ・購入配分

### 合成オッズの定義
選択した買い目 $i$ のオッズを $o_i$ とすると、

$$\text{合成オッズ} = \frac{1}{\sum_{i} \frac{1}{o_i}}$$

どの買い目が的中しても均等の払戻金を得られるように購入資金を配分した場合の実効倍率を表します。
（例: 10.0倍と15.0倍の2点選定時 $\rightarrow \frac{1}{0.1 + 0.0667} = 6.00\text{倍}$）

### 購入資金配分（100円単位丸め）
- 予算（円）を入力すると、資金比率 $\frac{1}{o_i}$ に応じて自動配分。
- 日本の投票券は100円単位のため、各買い目の金額を100円単位に丸め、丸め後の払戻期待額と合計購入額を表示します。

### オッズマトリクスと選択操作
- 1着艇（1〜6号艇）のタブを切り替え、2着×3着の表のセルをタップして買い目を自由に追加・解除可能。
- 「AI推奨買い目を選択」ボタンでAIが推奨した上位買い目をワンタップで一括選択。
- 「1着固定」「オッズ○倍以上/以下」「全解除」などの一括補助ボタンを完備。
- 公式サイトへの短時間過剰アクセスを防ぐため、「オッズ更新」ボタンには10秒間のインターバル制限を設けています。

## 8. 予想ロジック（統計モデル）の詳細

過去データ（2022-01〜2026-10-04、264,035レース）から、Plackett-Luce型の条件付きロジットモデルを最尤推定したパラメータを使用しています。

### 基本スコア式
$$\begin{aligned}
\text{score}_i = &\ \text{COURSE\_INTERCEPT}[c_i] \\
&+ 0.6347 \times (\text{全国勝率} - 5.5) - 0.0124 \times (\text{全国2連率} - 35) \\
&+ cL2' \times (\text{当地2連率} - 35) + cM2' \times (\text{モーター2連率} - 35) \\
&- \text{ST\_COEF}[c_i] \times (\text{平均ST} - 0.16) + \text{GRADE\_ADJ}[\text{級別}] \\
&- \text{EX\_COEF}'[c_i] \times (\text{展示タイム} - \text{平均展示}) + \text{windTerm}[c_i] \\
&- 0.1360 \times \max(0, \text{艇番} - 1 - c_i)
\end{aligned}$$

### 風向・風速モデル
風向コード（1〜16、17=無風）から追い風成分 $\tau = \cos((code - 5)\pi / 8)$ と横風成分 $\sigma = \sin((code - 5)\pi / 8)$ を算出し、風速超過量 $h = \max(0, w - 5)$ を加味した線形項で各コースへの有利不利を反映しています。

### 検証結果

| モデル（検証期間 69,916レース） | 3連単対数尤度 | 1着対数尤度 |
|---|---|---|
| 旧モデル（手設定） | −4.155 | −1.2254 |
| 最尤推定（風向なし） | −3.885 | −1.2167 |
| ＋風向 | −3.884 | −1.2160 |
| ＋着順別コース補正（**本実装**） | **−3.856** | **−1.2117** |

- 過去データ検証における回収率は控除率（約75%）に準じた約77〜79%の水準です。本モデルはオッズの歪み（市場のオッズ）を利用して回収率100%超を狙うものではなく、艇の実力・コース・展示・風から純粋に入線確率を統計的に推定するものです。

## 9. 免責事項

統計モデルによる参考値です。係数は過去約26万レースから推定したもので、的中を保証するものではありません。回収率は控除率の水準で、期待値の高い買い目を示すものではありません。買い目点数は各券種0〜30点まで指定できます。オッズは取得時点の参考値で、確定オッズではありません。合成オッズや期待値の目安は的中や利益を保証しません。舟券の購入は自己責任で行ってください。公式サイトへの過度な連続アクセスはお控えください。
